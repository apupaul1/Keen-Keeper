# 🫶 KeenKeeper — Keep Your Friendships Alive

KeenKeeper is a modern and responsive friendship management web application designed to help users stay connected with the people who matter most.

Users can manage friend information, track interactions, set relationship goals, and view their friendship activity through a clean and interactive interface.

## ✨ Features

- 👥 **Friend Management** — View and manage friendship information.
- 📜 **Interaction Timeline** — Track calls, texts, and video interactions.
- 📊 **Friendship Analytics** — View interaction statistics.
- 🔍 **Timeline Filtering** — Filter interactions by type.
- 📱 **Fully Responsive** — Works smoothly on mobile, tablet, and desktop.
- 🎨 **Modern UI** — Clean and user-friendly interface.

## 🛠️ Technologies

- **Next.js**
- **TypeScript**
- **Tailwind CSS**
- **DaisyUI**
- **React Icons**
- **React Hot Toast**

## LIVE URL : `http://localhost:3000`

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
